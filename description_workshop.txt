[h1]这个模组在做什么？[/h1]
原版城镇 NPC 只能看看、买买货。这个模组让 NPC 能跟你 [b]聊天[/b]、[b]装备武器[/b]、[b]一起开荒[/b]：你说一句「跟着我」，他就会跟随你；不填大模型 API Key 时，[b]跟随、装备、战斗照样能用[/b]，AI 对话和超能力是可选项。

[h1]主要功能[/h1]
[list]
[*][b]1. 对话式跟随[/b] — 聊天关键词让附近 NPC 跟随 / 解散，可在模组设置里改词。
[*][b]2. NPC 装备系统[/b] — 武器、弹药、强化之心；护士血蓝瓶、树妖增益药水槽。
[*][b]3. NPC 战斗系统[/b] — 跟随中且装备可用武器时自动攻击，小怪与 Boss 两套 AI。
[*][b]4. NPC AI 对话[/b] — 借用大模型能力；身边打字、@ 呼叫、跟随专属频道、主动搭话。
[*][b]5. NPC 超能力[/b] — 用自然语言触发，每个 NPC 能力不同，也可直接问他「你会什么超能力」。
[/list]

[h1]对话式跟随[/h1]
[list]
[*]在 NPC 附近打开聊天框，输入默认关键词 [b]「跟着我」[/b]，距离内最近的城镇 NPC 会开始跟随你。
[*]输入 [b]「你走吧」[/b]（默认）可让 [b]你当前跟随的那名 NPC[/b] 停止跟随。
[*]开始 / 停止的关键词可在 [b]模组配置 → AI Town NPCs 服务器配置[/b] 里修改。
[*]玩家只可以 [b]一名[/b] 跟随 NPC；别人正在带的 NPC，你不能用右键交互抢走，聊天里也会提示。
[*]护士、树妖正在身边施法（紧急治疗、群体结界）时，暂时不能对他用「跟着我」。
[/list]

[h1]NPC 装备系统[/h1]
右键城镇 NPC 打开对话，点 [b]装备[/b] 按钮：
[list]
[*][b]武器 / 弹药 / 强化之心[/b]（多数战斗型 NPC）：远程记得同时塞 [b]对应弹药[/b]。
[*][b]强化之心[/b]：工作台合成（5 生命水晶 + 5 神圣锭），每枚 +300 生命上限，单 NPC 最多 20 枚。
[*][b]护士[/b]：回血药、回蓝药槽 — 跟随中在战场帮你补血补蓝（不是战斗位，是专职奶妈）。
[*][b]树妖[/b]：9 个增益药水槽 — 开光环时会把槽内药水效果叠进光环并消耗药水；配合超能力做团队增益。
[/list]
[b]为什么护士、树妖不能拿武器？[/b]
定位是辅助：护士管生存，树妖管群体 Buff；战斗交给向导、军火商等城镇同伴。

[h1]NPC 战斗系统[/h1]
[list]
[*][b]前提[/b]：NPC [b]正在跟随你[/b]，且装备了 [b]能用的武器[/b]（含弹药类已配弹）。
[*]遇敌后会自动索敌、走位、躲弹幕、加速、大跳、短暂飞行等；内置 [b]小怪 AI[/b] 与 [b]Boss AI[/b] 
[*]跟随时若锁定 Boss，你跑太远会解除 Boss 锁定，NPC 会回到你身边继续跟。
[*][b]武器类型[/b]：近战、远程、魔法、召唤、投掷、哨兵、蓄力、悠悠球、骑枪、长矛、回旋镖等都可以给NPC使用，右键使用的武器就算了哟！
[/list]

[h1]NPC AI 对话[/h1]
需在服务器配置里 [b]开启 AI[/b] 并填写 [b]MiniMax / 火山方舟[/b]  API Key；没配好则只关闭 AI 与超能力，不影响装备与战斗。

[b]怎么聊？[/b]
[list]
[*][b]身边普通聊天[/b]：站在 NPC 约 [b]200 像素[/b]内（可在配置里选 50 / 100 / 200 / 300 / 400）直接打字；范围内 [b]只有 1 名[/b] 可对话 NPC 时才会接话，多人围一圈时不自动猜你要找谁。
[*][b]全图 @ 呼叫[/b]：聊天里写 [b]@NPC 名字[/b]（或别名如「向导」「护士」），全图找这名 NPC，不用站旁边。
[*][b]跟随专属频道[/b]：NPC 跟随时，对他私聊请用 [b]@[/b] 开头（或 @ 他的名字）；回复主要进 [b]「跟随」[/b] 聊天记录，不刷屏公共频道。没跟随时，@ 只认 [b]你正在带的那名[/b] 跟随 NPC。
[*][b]主动发言[/b]：你在 NPC 旁约 50 像素内停留约 10 秒，可能被打招呼；跟随途中也会根据环境碎碎念（换 biome、天亮、附近 Boss、低血量等）。
[*]聊天记录分 [b]「全部」[/b] 与 [b]「跟随」[/b]；每名玩家与每名 NPC 有 [b]短期记忆[/b]。
[*]同一 NPC 多人同时找他说话时会 [b]排队[/b]；你 @ 他时，回复前会带 [b]@你的名字[/b]。发言过快会限流提示。
[/list]

[h1]NPC 超能力[/h1]
用 [b]自然语言[/b] 在对话里触发（需开启超能力 + AI对话），NPC 也可能 [b]拒绝你[/b]。不确定就问：「你会什么超能力？」

[b]说法接近即可：大模型会判断你的意图[/b] 目前只做了；以下NPC的超能力
[list]
[*][b]向导[/b]：「给我下点雨」「别下了」「来场沙尘暴」「刮点风」；「把掉落物清掉」；「丛林在哪」「金矿在哪」「生命水晶在哪」
[*][b]护士[/b]：「救我」「我要死了」「快来救我」
[*][b]树妖[/b]：「来个增益」「来个群体」
[*][b]军火商[/b]：「给我一把枪」「给把武器啊」
[*][b]商人[/b]：「收垃圾」「垃圾要吗」；「送点火把」「送点绳子」「送点药水」
[*][b]爆破专家[/b]：「帮我炸开这里」「炸开这里」；「请求火力支援」「扔雷掩护我」
[*][b]哥布林工匠[/b]：手里拿着武器时说「重铸」「加个词缀」「附魔一下」
[*][b]机器侠[/b]：「请求火力覆盖」「火力不足求支援」
[*][b]税收官[/b]：「给我点钱」「我穷死了」
[/list]

[h1]FAQ[/h1]
[b]Q：NPC 可以装备哪些武器？[/b]
A：战斗型 NPC 可塞各类武器；需要弹药的务必配弹药。护士 / 树妖走药品与 Buff 槽，不能装备武器。

[b]Q：NPC 是如何战斗的？[/b]
A：仅 [b]跟随 + 有可用装备[/b] 时自动开战；小怪与 Boss 行为不同，会移动、躲弹、跳跃与短时飞行。

[b]Q：不联网 / 不填 Key 能玩吗？[/b]
A：能。装备、跟随、战斗是核心；AI 与超能力需要能访问的大模型服务。

[b]Q：多人能玩吗？[/b]
A：[b]支持联机[/b]（专用服务器 + SSC 云存档场景已重点测过）

[b]Q：和别的模组冲突吗？[/b]
A： [b]灾厄[/b] 试过可玩；其它模组未逐一验证，遇问题欢迎反馈。

[b]Q：超能力只能通过大模型触发吗？[/b]
A：是的，因为要通过大模型来判断你对话中的意图，模组内置只支持  minimax与火山方舟，这2个厂商都可以订阅 coding-plan计划，已经白菜价了，火山方舟最低10月一个月，给模组使用绰绰有余。
