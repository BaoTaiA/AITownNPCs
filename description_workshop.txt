城镇 NPC 可以拿你的武器跟着你打仗，也可以在聊天里回话。AI 对话和超能力可选：不填 API Key 时，装备、跟随和战斗仍然可用。

[h1]模组功能[/h1]

[b]装备与战斗[/b]
[list]
[*]可以把近战、远程、魔法、召唤等武器交给城镇 NPC。远程需要对应弹药。NPC 跟随你时会自动攻击，魔法由 NPC 自己施放。
[*]聊天里说「跟着我」，附近的 NPC 会跟着你并自动战斗。说「你走吧」则停止跟随。两个关键词都可以在模组配置里改。
[*]护士可装备回血药、回蓝药，战场上帮你补血补蓝。
[*]树妖有 9 个增益药水槽。她开出光环时，会把槽里的药水效果加到光环上，并消耗对应药水。
[*]工作台合成「强化之心」（5 个生命水晶 + 5 个神圣锭），放进 NPC 的强化之心槽。每枚 +300 生命上限，最多 20 枚。
[/list]

[b]AI 聊天[/b]
[list]
[*]默认在约 200 像素内打字，附近的 NPC 会回应。距离可选 50 / 100 / 200 / 300 / 400 像素。
[*]聊天框 @NPC 名字，可以全图呼叫。
[*]在约 50 像素内停留大约 10 秒，NPC 可能主动打招呼，跟随途中会碎碎念。
[*]聊天记录分「全部」和「跟随」两个页签。
[*]每个NPC都有短期记忆。
[/list]

[b]超能力[/b]
和 NPC 对话时，会按你说的话触发该 NPC 的超能力，想知道某个 NPC 还能做什么，直接 @ 他，问「你有什么超能力」。
多数超能力有冷却，NPC也会按概率拒绝你。
[list]
[*]向导：调整天气、清除地面掉落物、按地图记忆指路
[*]护士：紧急治疗（传到身边，回满血并清除减益，再给 1 分钟超级爱心，8 秒后回去）
[*]树妖：群体增益（身上有增益药水时传到身边放一次结界，8 秒后回去）
[*]军火商：临时配枪（约 5 分钟后收回，附带 800 发子弹）
[*]商人：收购背包里的垃圾、紧急送来火把、绳子、药水、弹药等
[*]爆破专家：在面前放粘性雷管，手榴弹做火力覆盖
[*]哥布林工匠：改写你手持武器的词缀
[*]机器侠：用火箭做火力覆盖
[*]税收官：有概率施舍 50 金币
[/list]
说法接近即可，例如：
[list]
[*]向导：「下雨」「别下了」「来场沙尘暴」「打雷」「大风天」「晴天」；「把地上的东西清掉」；「丛林在哪」「金矿在哪」「生命水晶在哪」
[*]护士：「救我」「我要死了」「快来救我」
[*]树妖：「来个增益」「来个群体」
[*]军火商：「给我一把枪」
[*]商人：「收垃圾」「帮我把垃圾卖掉」；「送点火把」「送点绳子」
[*]爆破专家：「放雷管」「炸开这里」；「火力支援」「扔雷掩护」
[*]哥布林工匠：手里拿着武器，说「重铸」「加个词缀」「附魔」
[*]机器侠：「火力支援」
[*]税收官：「给我点钱」
[/list]

[h1]注意事项[/h1]
[list]
[*]在「模组配置 → AI Town NPCs 服务器配置」里选择模型并填写 API Key。目前支持 MiniMax 和火山方舟。
[*]目前只能单机使用，多人暂不支持。
[*]没填可用的模型或 API Key 时，AI 对话和超能力会自动关闭，进世界时会提示。装备、跟随和战斗不受影响。
[*]AI 回复需要能访问对应大模型服务。发言太快会被限流。
[/list]
